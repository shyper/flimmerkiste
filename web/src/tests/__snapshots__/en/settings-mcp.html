MCP

With the Model Context Protocol (MCP) you ask an AI such as Claude “What's on tonight?”, let it search your library or set up a channel. Each app gets its own token with exactly the rights you give it.

1. Create a token

Permissions Tip: for questions about the guide and the library the first two are enough. “Change channels” only if the AI should set up channels; “Delete channels” best never.

2. Connect your AI

Safest is an app that sends the token as a header: Claude, Claude Code and the editors can. Only for apps that can't, such as ChatGPT, the token goes into the address.

  1. Open claude.ai and go to Customize → Connectors → “+” → Custom connector.
  2. Name: Flimmerkiste. As the URL this address:
    http://192.168.1.10:8080/mcp
  3. For Authentication choose “No sign in”.
  4. Under “Request headers” add a header named Authorization with this value:
    Bearer
  5. Add it. The connector belongs to your Claude account, so it is also there in the Claude app on your phone.

Claude connects from Anthropic's data center: Flimmerkiste has to be reachable over HTTPS from the internet. The free Claude plan allows one custom connector.

This page is open at http://192.168.1.10:8080/mcp. The app needs your public HTTPS address: open the settings through your domain, then the right address shows here.
